隱私權政策

應用程式：Horazon_YT ｜ 最後更新：2026 年 9 月 20 日

這是什麼

Horazon_YT 是一支個人自用的命令列工具，用來維護 Unity短片辭典 這個教學影片專案在 YouTube 上的內容。它只在作者本人的電腦上執行， 只存取作者本人的 YouTube 頻道，沒有對外提供服務，也沒有其他使用者。

存取哪些資料

本工具透過 YouTube Data API v3 要求以下授權範圍：

  • https://www.googleapis.com/auth/youtube.force-ssl

用途僅限於對作者自己頻道上的影片執行下列操作：

  • 更新影片的標題、說明、標籤、分類與語言設定
  • 上傳與更新字幕檔
  • 建立播放清單，並把影片加入播放清單
  • 讀取頻道名稱與上傳清單，用來核對影片 ID

資料怎麼被儲存

  • OAuth 存取權杖只寫在本機檔案 videos/.youtube-token.json，不會上傳到任何伺服器。
  • 本工具沒有後端服務、沒有資料庫、沒有分析追蹤，不會把任何資料傳送給第三方。
  • 除了 Google 自己的 API 端點之外，本工具不會與任何外部服務通訊。
  • 作者可隨時到 Google 帳戶權限頁 撤銷授權；撤銷後刪除上述權杖檔案即可清除本機殘留。

不做哪些事

  • 不收集、不儲存、不販售任何個人資料。
  • 不存取他人的 Google 帳戶或 YouTube 頻道。
  • 不使用 Google 使用者資料訓練任何模型。

English summary

Horazon_YT is a personal command-line tool used by a single individual (the author) to maintain their own YouTube channel for the Unity短片辭典 tutorial project. It runs locally on the author's own machine and has no other users.

It requests the youtube.force-ssl scope solely to update video metadata (title, description, tags, category, language), upload caption tracks, create playlists and add the author's own videos to them, and read the channel's upload list to resolve video IDs.

The OAuth token is stored only in a local file on the author's computer. There is no server, no database and no analytics. No data is transmitted to any third party, and no Google user data is used to develop, improve or train generalized AI or ML models. Access can be revoked at any time via Google Account permissions.
