【BA08】Asset Store 與 Package Manager

── 標題 ──
Asset Store 與 Package Manager｜Unity短片辭典

── 說明 ──
Asset Store 是 Unity 的素材商店，用 Unity 帳號登入，可以買素材、模板，也有很多免費資源。找到後按加入 My Assets（付費的要先購買），回到 Unity 在 Package Manager 先 Download、再 Import 才會進專案。Package Manager 還能看 In Project 已裝的內容、Unity Registry 的官方套件、Built-in 內建功能與 Services 服務。
